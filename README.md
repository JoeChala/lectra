# Lectra RAG

A local-first multimodal RAG system for studying from college notes, textbooks, lectures, and other educational material.

## Goals

- Multimodal document retrieval
- Course-aware retrieval
- Evidence-backed citations
- Mixed-source note generation
- Graph-guided retrieval experiments
- Local model support
- Laya-based decision experiments

## Stack

- Python
- uv
- FastAPI
- LangChain
- Qdrant
- Laya
- Pyrefly
- Ruff
- pytest
